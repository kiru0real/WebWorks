# ГОРШОЧЕК — ресторан русской кухни

Современный адаптивный сайт ресторана с меню из SQLite, новостями, админ-панелью, авторизацией и заготовками для Яндекс Карт и виджета отзывов.

## Стек

- Node.js 22+
- Express
- SQLite через `better-sqlite3` 13 (нативный модуль на базе Node-API)
- Сессии администратора также хранятся в SQLite
- HTML, CSS и vanilla JavaScript на фронтенде

## Совместимость с Helmet

Content Security Policy передаётся в Helmet в формате `{ directives: { ... } }`. Не оборачивайте объект `csp` повторно в `directives`: это вызывает ошибку `directiveValue is not iterable` при старте сервера.

## Быстрый запуск

1. Установите Node.js 22 или новее (рекомендуется актуальная LTS-версия).
2. В корне проекта выполните:

   ```bash
   npm install
   ```

3. Скопируйте `.env.example` в `.env` (`cp .env.example .env` на macOS/Linux или `Copy-Item .env.example .env` в PowerShell). Замените `SESSION_SECRET` на длинную случайную строку. При необходимости задайте `ADMIN_USERNAME` и `ADMIN_PASSWORD`. Если пароль оставлен как placeholder или не задан, сервер сгенерирует одноразовый пароль и выведет его в консоль при первом запуске.
4. Запустите сайт:

   ```bash
   npm run dev
   ```

5. Откройте [http://localhost:3000](http://localhost:3000).
6. Админ-панель: [http://localhost:3000/admin](http://localhost:3000/admin).

При первом запуске создаётся SQLite-база `data/gorshochek.sqlite` и демонстрационное меню. Не удаляйте папку `data/` при обновлении зависимостей: в ней хранится ваша база данных. Учётная запись администратора создаётся при первом запуске на пустой базе. Если задан настоящий `ADMIN_PASSWORD`, будет использован он; если пароль не задан или оставлен placeholder из `.env.example`, сервер сгенерирует пароль и выведет его в консоль.

> Важно: переменные `ADMIN_USERNAME` и `ADMIN_PASSWORD` используются только при первом создании администратора. После этого пароль хранится в виде bcrypt-хеша в базе. Для сброса учётной записи нужно выполнить резервное копирование базы и пересоздать `admins` либо добавить отдельный механизм сброса пароля.

## Яндекс Карты

1. Получите ключ для JavaScript API в [Кабинете разработчика Яндекса](https://developer.tech.yandex.ru/).
2. Добавьте его в `.env` как `YANDEX_MAPS_API_KEY`.
3. В админ-панели откройте «Настройки ресторана», укажите адрес и координаты широты/долготы.
4. Перезапустите сервер после изменения `.env`.

Карта создаётся через JavaScript API 2.1. Ключ передаётся браузеру, поэтому ограничьте его по HTTP Referer в кабинете Яндекса. Официальная инструкция: https://yandex.ru/dev/jsapi-v2-1/doc/ru/

## Отзывы Яндекса

Для блока отзывов предусмотрено поле `Ссылка на виджет отзывов Яндекса` в админ-панели. Откройте карточку ресторана в Яндекс Картах → «Поделиться» → «Виджет с отзывами», скопируйте URL `src` из сгенерированного iframe и вставьте его в поле настроек.

Яндекс позволяет публиковать автоматически генерируемый виджет отзывов на сайте; рекомендуемая ширина — 300–760 px, высота — от 500 px. Справка: https://yandex.ru/support/maps/ru/concept/get-map-reference

## Админ-панель

- Управление блюдами: добавление, редактирование, удаление, доступность, категория, цена, вес, изображение и отметка «Хит».
- Новости: создание, редактирование, удаление и публикация/снятие с публикации.
- Настройки: адрес, контакты, часы работы, координаты карты, ссылка на карточку организации и URL виджета отзывов.

Изображения меню и новостей задаются URL-адресами. Для реального проекта рекомендуется загрузка файлов в объектное хранилище и проверка изображений на сервере.

## Перед публикацией

- Замените демонстрационные блюда/изображения, адрес, телефон и часы работы на реальные.
- Установите сильный `SESSION_SECRET` и пароль администратора.
- Работайте только через HTTPS в production.
- Ограничьте ключ Яндекс Карт по домену.
- Настройте резервное копирование SQLite и политику хранения персональных данных.
- Подключите реальную форму бронирования/заказа, если она понадобится: сейчас сайт представляет меню и информацию о ресторане, но не принимает онлайн-заказы.

## Админ-панель: устранение неполадок

Если после входа панель открывается, но разделы и список блюд остаются пустыми, проверьте консоль браузера. В актуальной версии `src/public/admin.js` определён общий селектор `$$`, используемый навигацией. После изменения файлов перезапустите сервер и обновите страницу без кэша (`Ctrl + F5`).

Данные блюд хранятся в `data/gorshochek.sqlite`. Не удаляйте этот файл при обновлении проекта: в нём находятся блюда, новости, настройки и учётные записи администраторов. Если таблица блюд действительно пуста, при следующем старте сервер добавит стартовые позиции только если в ней нет ни одной записи.
