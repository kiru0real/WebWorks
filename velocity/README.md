# VELOCITY PREMIUM — Ultimate Edition

A polished responsive premium-car showroom concept built with plain HTML, CSS and JavaScript.

## Run
1. Extract the archive.
2. Open `index.html` in a modern browser, or run it using VS Code Live Server.
3. An internet connection is required for remote Unsplash photos and Google Fonts.

## Features
- Scroll reveal animations with reduced-motion accessibility support
- Vehicle catalog with search, category/brand/price filters and sorting
- Dedicated vehicle detail modal
- Finance calculator with credit and lease estimates
- Photo gallery with arrows and thumbnails
- Compare up to three vehicles
- Favorites stored in localStorage
- Demo admin panel to add/delete/reset catalog entries
- Responsive mobile navigation
- Demo test-drive form

## Important
This is a portfolio/demo front end. Catalog and prices are sample data. The admin panel is local-only and is not secure; changes are stored in the browser. The form does not send requests to a server. For production, connect a backend, validation, authentication, and real inventory/pricing data.


### Изображения
Автомобильные изображения включены в папку `assets/` и работают без внешних фотохостингов. Для шрифтов Google Fonts интернет может потребоваться; без него используются системные запасные шрифты.


### Автомобильные изображения
В этой сборке используются встроенные фотореалистичные изображения автомобилей; они включены в HTML/JavaScript и не загружаются с внешних сайтов.


### Исправление каталога
При первом открытии каталог сбрасывает временные фильтры и показывает все автомобили. Кнопка «Все автомобили» также сбрасывает поиск, марку, бюджет и сортировку.
